# 公司 Logo 文件

请将以下公司的 logo 文件放置在 `/public` 目录下：

## 需要的 Logo 文件

1. **bytedance_logo.svg** - 字节跳动 logo
2. **tencent_logo.svg** - 腾讯 logo  
3. **alibaba_logo.svg** - 阿里巴巴 logo

## 获取 Logo 的方式

1. 从公司官网下载官方 logo
2. 使用 [Worldvectorlogo](https://worldvectorlogo.com/) 下载 SVG 格式
3. 使用 [Brandfetch](https://brandfetch.com/) 获取品牌资源

## Logo 规格建议

- 格式：SVG（矢量图，可缩放）
- 尺寸：建议 512x512 或保持原始比例
- 背景：透明背景
- 颜色：保留原始品牌色

## 临时方案

如果暂时没有 logo 文件，可以：
1. 使用文字代替（修改 ExperienceCard.ts 中的 img 标签）
2. 使用公司首字母作为占位符
3. 使用纯色圆形作为临时 logo
